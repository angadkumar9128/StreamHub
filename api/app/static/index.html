Quick start

  1. Create a stream.
  2. Publish an event or upload CSV/JSONL/NDJSON/Parquet.
  3. Open the stream and inspect live tail/offsets.
  4. Use the Databricks tab for the Kafka endpoint and notebook configuration.

Data flow

Producer / File → StreamHub API → Redpanda → Consumer groups / REST → Databricks Structured Streaming → Delta Bronze → Silver → Gold
